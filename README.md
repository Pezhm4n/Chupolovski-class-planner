## معرفی

برنامه گُلستون کلاس پلنر به دانشجویان کمک می‌کند بهترین جدول زمانی خود را بسازند: از جستجوی دروس و چیدمان تعاملی گرفته تا کارنامه واقعی، گزارش ۲۷۲ و نظرسنجی اساتید — همه در یک برنامه‌ی سریع و بومی ویندوز که **بدون اینترنت هم** کار می‌کند.

## امکانات

### 📅 برنامه‌ریزی هفتگی
- جدول تعاملی شنبه تا پنج‌شنبه، **۷ تا ۲۰** با هدر ساعتی تمیز
- رنگ اختصاصی و پایدار برای هر درس + چیپ‌های «فرد/زوج» + دکمه حذف سریع
- **تشخیص تداخل** زمانی و امتحانی، پیش‌نمایش هاور و کارت کامل جزئیات درس با کلیک
- دروس زوج/فرد روی یک اسلات با ویجت دوگانه

### 🔎 جستجو و مدیریت دروس
- فهرست مجازی‌شده‌ی هزاران درس (سقف نمایش + راهنمای جستجو = بدون لگ و کرش)
- فیلتر رشته، جستجوی فارسی هوشمند (ي/ی، ك/ک)، افزودن/ویرایش درس سفارشی
- کاتالوگ همیشه از سرور پروداکشن تازه می‌شود و در SQLite کش می‌شود

### 🎓 داشبورد تحصیلی (کارنامه واقعی)
- سینک امن کارنامه از سامانه گلستان از طریق بک‌اند ابری
- نمودار روند معدل، فیلتر ترم، رنگ‌بندی قبول/مردود
- **گزارش ۲۷۲** با نوار پیشرفت واقعی هر دسته

### 👨‍🏫 نظرسنجی اساتید (کامل، معادل نسخه وب)
- انتخاب گروه و استاد از دایرکتوری زنده؛ آمار با فرمول رسمی و ادغام تلگرام
- ثبت/ویرایش/حذف نظر کاملاً ناشناس، مقایسه ۳ استاد، محبوب‌ترین‌ها، پیشنهاد استاد جدید
- درگاه «نظر بده تا ببینی»

### 🌗 تم و 🌐 زبان
- تم **روشن / تاریک / هم‌راستا با سیستم** — اعمال زنده روی کل برنامه
- دو زبانه‌ی کامل فارسی/انگلیسی (RTL/LTR) با ذخیره‌ی انتخاب

### ☁️ حساب ابری و همگام‌سازی
- ثبت‌نام/ورود با JWT، ذخیره و بازیابی برنامه‌ها روی ابر + پشتیبان محلی خودکار

### 📝 امتحانات و خروجی‌ها
- تقویم امتحانات با هایلایت تداخل؛ خروجی **PDF، HTML، CSV، تصویر**

## نصب و اجرا

```bash
# 1. دریافت ریپو
git clone https://github.com/Pezhm4n/Chupolovski-class-planner.git
cd Golestoon-class-planner

# 2. محیط مجازی (پیشنهاد)
python -m venv venv
venv\Scripts\activate            # Windows

# 3. نصب وابستگی‌ها
pip install -r app/requirements.txt

# 4. اجرا
cd app
python main.py
```

> فایل `.env` لازم نیست؛ برنامه به‌صورت پیش‌فرض به سرور پروداکشن وصل می‌شود. برای توسعه‌ی محلی الگوی `app/.env.example` را ببینید.

## راهنمای استفاده
1. از منوی «داده‌ها» دروس را دریافت کنید (یا از کش محلی ادامه دهید)
2. از فهرست، رشته/درس را انتخاب و روی درس کلیک کنید تا روی جدول قرار بگیرد
3. با کلیک روی هر سلول، جزئیات کامل درس + حذف از برنامه
4. «تنظیمات» → ظاهر و زبان؛ «خدمات تحصیلی» → کارنامه و گزارش ۲۷۲
5. برنامه نهایی را در «ترکیب‌های ذخیره‌شده» یا ابر ذخیره کنید

## معماری

| لایه | اجزا |
|:--|:--|
| UI (PyQt5) | `app/ui/` — پنجره اصلی، داشبورد، دیالوگ‌های دامنه‌ای + کنترلرها/بیلدرها |
| Business | `app/core/` — منیجرهای QThread (academic/professor/sync)، موتور برنامه‌ریزی، تم، i18n |
| Network | `app/core/network/` — Session با pooling + کلاینت‌های Auth/Schedule/Transcript/Professor/Proxy |
| Data | `app/data/` — SQLite لوکال (کاتالوگ دروس + پروفایل هر دانشجو + بکاپ‌ها) |

- تمام عملیات شبکه در **QThread** (بدون فریز UI) با fallback آفلاین به SQLite
- اعتبارنامه‌های گلستان فقط محلی ذخیره و صرفاً از طریق هدرهای HTTPS به سرور ارسال می‌شوند
